# FlixTV

FlixTV é um player de mídia para reproduzir canais ao vivo, filmes e séries de uma fonte compatível que você já possui e está autorizado a acessar.

## Recursos

- Navegação por categorias e busca.
- Perfis, favoritos e continuar assistindo.
- Organização de temporadas e episódios.
- Controle parental por PIN.
- Demonstração técnica para conhecer o player sem informar uma conta.

A disponibilidade de recursos varia conforme a plataforma e a versão instalada. A reprodução depende da conexão, do serviço de origem e dos formatos suportados pelo aparelho.

## Acesso e conteúdo

O FlixTV não fornece canais, filmes, séries, playlists, assinaturas ou contas de serviços de conteúdo. Para acessar uma fonte externa, utilize os dados de um serviço compatível que você esteja autorizado a usar. O suporte do player não cria contas nem fornece acesso a conteúdo.
